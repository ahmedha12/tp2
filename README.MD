# TP HTML - Structural & Validation

## Résumé du TP
Ce TP consiste à appliquer les bonnes pratiques de structuration HTML, à respecter les règles d'imbrication des balises (Bloc vs Inline) et à valider le code avec le validateur W3C.

## Liste des balises textuelles abordées
- **Balises de bloc (Block):** `<div>`, `<h1>` à `<h6>`, `<p>`, `<ul>`, `<li>`, `<pre>`
- **Balises en ligne (Inline):** `<span>`, `<a>`, `<code>`, `<strong>`, `<em>`
